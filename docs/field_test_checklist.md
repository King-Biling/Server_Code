现场联调清单（建议）
=====================

准备检查
- ORDER 与拓扑矩阵一致，且 PREP 阶段后车能看到前车状态。
- GUIDE 方向与速度单位在车端与服务器一致。
- AprilTag 字典一致（若使用 AprilTag，确认 DICT 类型）。

联调步骤
1. 启动服务器并确认广播端口、Web 控制页可访问。
2. 广播 PREP，确认每车都能接收前车状态。
3. 广播 ORDER，确认每车能回 PREP_OK。
4. 单车执行 STEP + 图像上传，确认 IMG_META/IMG_CHUNK 重组成功且 GUIDE 按频率刷新。
5. 逐车串行执行 STEP，确认 DONE=1 后车端立刻停车并回 STEP_OK。
6. 全部完成后检查 DONE 广播与拓扑恢复。

排障提示
- PREP 卡住：先查前车状态是否可见，再重发 PREP/ORDER。
- 图像重组失败：检查 SEQ/IDX/TOT/LEN 是否一致，确认没有 Base64 二次编码。
- GUIDE 超时：检查服务器是否持续刷新，建议 50-100ms。

参数调优起点
- 图像重组超时：400 ms
- 每车会话窗口：1-3
- PREP 重试超时：3 s
- PREP 重试间隔：1-2 s
- GUIDE 刷新频率：10-20 Hz
